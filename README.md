# Джобен молитвеник (Android)

Приложение с молитви и библейски стихове за членовете на нашата Telegram група.
Пишеш дума като „здраве“, „път“, „страх“ или „деца“ и излизат подходящите молитви и стихове.

## Какво може

- **Търсене по ключови думи.** Разпознава различни форми на думата („болен“, „болни“, „болест“; „път“, „пътуване“).
- **Категории:** Основни молитви, Здраве, Семейство и деца, Път и работа, Утеха и скръб, Вяра и упование, Благодарност, Сутрин и вечер, За групата.
- **Стих за деня** на началния екран. Еднакъв е за всички в групата.
- **Любими** (♡) и **размер на шрифта** (A− / A+). Полезно е за по-възрастните членове.
- **Споделяне:** бутон „В Telegram“ отваря директно Telegram с готовия текст. Има и бутони за споделяне и копиране.
- **Молитвен списък:** записваш имената на членовете и за какво да се молим, а приложението сглобява обща молитва и я изпраща в групата.
- **Църковен календар:** празник на деня, имени дни, пост, предстоящи празници и търсене „кога има имен ден…“. Великден се изчислява автоматично.
- **Чотка:** брояч за Иисусовата молитва с вибрация (33 / 50 / 100 / без край).
- **Четене на глас** (▶) с българския глас на телефона.
- Работи **без интернет**. Всичко се пази само на телефона.
- Светла тема с топли цветове.

## Как се пуска нова версия

1. Вдигни `versionCode` и `versionName` в `app/build.gradle.kts`.
2. Обнови `RELEASE_NOTES.md`.
3. Android Studio → Build → Generate Signed App Bundle / APK → APK → release, със същия ключ като предишната версия.
4. Качи APK файла в GitHub → Releases → Draft a new release.

## Как се компилира локално

1. Разархивирай папката и я отвори в **Android Studio**: File → Open → `Molitvenik`.
2. Изчакай Gradle Sync. Ако Android Studio предложи да обнови версиите на AGP или Kotlin, може да ги приемеш.
3. **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
4. APK файлът е в `app/build/outputs/apk/debug/app-debug.apk`. Можеш да го изпратиш директно в Telegram групата.

За Google Play трябва подписан release build: Build → Generate Signed App Bundle / APK.

## Как се добавят молитви

Всичко е в `app/src/main/assets/prayers.json`. Нова молитва изглежда така:

```json
{
  "id": "p26",
  "type": "молитва",
  "title": "Заглавие",
  "category": "Здраве",
  "source": "Джобен молитвеник",
  "tags": ["ключова дума", "друга дума"],
  "text": "Текст на молитвата.\nНов ред се прави с \\n.\nАмин."
}
```

- `type` е `"молитва"` или `"стих"`.
- `category` трябва да е от списъка `categories` в началото на файла.
- В `tags` пиши думите, по които хората биха търсили. Включи и разговорни думи, например „гурбет“, „задушница“ и „интервю“.
- `id` трябва да е уникален.

## Бележка за текстовете

- Библейските стихове са по **Синодалния превод (1925)**. Свери точния текст с печатна Библия, преди да разпространиш приложението.
- Традиционните молитви (Отче наш, Царю Небесни, Богородице Дево, Достойно е) са в разпространения църковен вариант на български.
- Останалите молитви са написани за приложението. Добре е да ги прегледа свещеник от енорията.
